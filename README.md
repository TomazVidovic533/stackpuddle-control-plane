# StackPuddle Control Plane

Planned Go control plane for [StackPuddle](https://github.com/TomazVidovic533/stackpuddle): the execution engine, the authenticated operation API, reconciliation and durable state, and runtime adapters, packaged as a container image.

The command-line interface lives in [StackPuddle CLI](https://github.com/TomazVidovic533/stackpuddle-cli). Shared schemas and infrastructure modules live in the main StackPuddle repository.

## Status

Early development. This repository currently contains only this introductory README. No installable release is available yet.
