package engine // import "github.com/TomazVidovic533/stackpuddle-control-plane/engine"

Package engine is the only public package of the control plane: a Go library
the command-line interface runs in-process. It submits, inspects and cancels
operations on one environment of a loaded project and advertises what it can
run.

There is no listener, transport or login here. Everything else lives under
internal/.

type Engine struct {
	// Has unexported fields.
}
    Engine runs operations. It is safe for concurrent use by operations on
    different environments.

func New(opts Options) (*Engine, error)
    New composes the engine: settings from the environment, the explicit module
    catalog, the local secret provider and the Compose runtime adapter. It reads
    no file and starts no process.

func (e *Engine) Advertise() model.EngineInfo
    Advertise reports the version, the capabilities and the state and store
    versions this engine reads and writes. The capabilities are the runtime,
    the secret providers and the module drivers.

func (e *Engine) Cancel(ctx context.Context, req CancelRequest) error
    Cancel asks the running operation to stop between steps. It writes
    cancel/<id>.json and nothing else, and takes no lock.

func (e *Engine) Inspect(ctx context.Context, req InspectRequest) (Inspection, error)
    Inspect reads state without the lock and writes nothing, so it works while
    another operation runs and needs no secrets key.

func (e *Engine) Run(ctx context.Context, req RunRequest) (Result, error)
    Run invokes one job and nothing else: it records an operation with the
    command run holding the provider and access steps the job needs and exactly
    one job step. The job runs even when its spec is unchanged, and each
    invocation is a new operation with its own ID, so the invocation ID is the
    operation ID and the step ID. The job's native exit code is on the step
    (Step.Job); a non-zero code fails the operation with job.exited_nonzero,
    apart from a runtime failure of the engine. A job runs only here or as the
    prerequisite of a service that is up, never because a group was selected.
    When an operation was recorded but did not succeed, Run returns it with the
    error.

func (e *Engine) Submit(ctx context.Context, req SubmitRequest) (Result, error)
    Submit changes the environment as the request says. A dry run takes no lock
    and writes nothing. When an operation was recorded but did not succeed,
    Submit returns it with the error.

type Options struct {
	// LookupEnv reads one environment variable; the process passes os.LookupEnv. It is required and is
	// the only way the engine reads its environment.
	LookupEnv func(key string) (string, bool)
	// Now supplies the clock; nil uses time.Now. Values are converted to UTC.
	Now func() time.Time
	// Random supplies identifiers, temporary-file suffixes and jitter; nil uses crypto/rand. Secret
	// values and encryption nonces never come from it: the local secret provider always draws them
	// from crypto/rand, so a deterministic reader cannot repeat a nonce or make a secret predictable.
	Random io.Reader
}
    Options configure New.

type RunRequest struct {
	Scope Scope
	// Project is loaded by the caller; the engine refuses it while Unresolved() is non-empty.
	Project model.Project
	// ProjectDir is the absolute project directory; build contexts must stay inside it.
	ProjectDir string
	// Job is the job to invoke, as a workload reference. A reference to anything that is not a job
	// is validation.unknown_object.
	Job model.ObjectRef
	// Inputs are resolved by the caller. Job arguments are not accepted in m01.
	Inputs []InputValue
	// DryRun plans the invocation and writes nothing.
	DryRun bool
	// Wait is how long to wait for a busy environment; zero fails at once.
	Wait time.Duration
	// Progress, if set, is called after every persisted change, on Run's goroutine.
	Progress func(Operation)
}
    RunRequest is one explicit invocation of a job.
